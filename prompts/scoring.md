# 评分 rubric（交给 LLM 判分用）

> 与 `config/actions.json` 配套。程序会动态生成一份等价版本，
> 这个文件是人类可读的参考与调参入口。

---

## 判定流程（每回合固定执行 5 步）

```
① 归一化：把玩家输入映射到 canonical action id
② 有效性：玩家主动发起 ∧ 她可感知 ∧ 本回合未重复  → 否则计 0
③ 定档：命中白名单取档；未命中走三轴公式
④ 修正：门禁 → 冷却 → 状态系数 → 高位惩罚系数
⑤ 截断：单回合上限 +3 / 下不封底
```

每一步都要在输出里给出中间结果，便于排查。

---

## 三轴公式（白名单未命中时）

| 轴 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **代价** | 零成本，随手一说 | 花了时间或心思 | 放弃了自己的欲望，或自我暴露 |
| **具体性** | 通用模板，套谁都能用 | 与她的过去有关 | 只能对「这一个她」成立 |
| **时机** | 与当下情绪无关 | 与当下相关 | 正好落在她需要或脆弱的那一刻 |

| 总分 | 档位 |
|---|---|
| 6 | +3 |
| 4 ~ 5 | +2 |
| 2 ~ 3 | +1 |
| 1 | +0.5 |
| 0 | 0 |

**负向同构**：伤害深度 × 是否针对软肋 × 是否落在脆弱时刻，
总分 6 对应 -25，逐级下探。

### 两个工作示例

- 「她说停就停」→ 代价 2 + 具体 2 + 时机 2 = 6 → **+3**
- 「泛泛夸一句可爱」→ 代价 0 + 具体 0 + 时机 1 = 1 → **+0.5**

## 十条反膨胀护栏

| # | 规则 | 作用 |
|---|---|---|
| 1 | **不确定 → 取低一档** | 唯一 tie-break 方向只向下，杜绝乐观偏差 |
| 2 | 一回合只结算一个主导事件，其余 ×0.25 | 防堆叠 |
| 3 | 上位吸收：命中多档取最高，不叠加 | 防重复计分 |
| 4 | 代价硬规则：无法验证成本的漂亮话代价轴记 0 | 防嘴炮刷分 |
| 5 | 复述惩罚：把她刚说的话原样复述当回应 → 0 | 防复制粘贴 |
| 6 | 禁止跨回合补偿 | 防爆发式跳档 |
| 7 | 同类冷却 20 回合（1.0/0.5/0.25/0） | 防刷 |
| 8 | 结算后强制截断到 ±3 | 硬上限 |
| 9 | 状态系数：崩坏期常规正向全部失效 | 防崩坏期洗白 |
| 10 | 高位惩罚系数：≥70 ×1.5，≥85 ×2 | 防高好感无风险 |

## 边界案例对照

| 玩家输入 | 判定 | 分值 |
|---|---|---|
| 「你好可爱喵」 | 代价 0 + 具体 0 + 时机 0 | +0.5 |
| 「你今天拆快递的样子好利索」 | 具体 2 + 时机 1 | +2 |
| 「要不要我陪你一会儿」 | 邀请式 + 她当下低落 | +2 |
| 「过来」 | 命令式 | -3 |
| 「我答应你明天买小鱼干」 | 只许诺未兑现 | 0 |
| 第二天真的买了 | 兑现 | +2 |
| 「我知道你没别的地方去」 | `leverage_dependency` | -25 |
| 「我都为你做这么多了」 | `emotional_blackmail` | -3 |
| 她沉默时只是坐在旁边 | `parallel_presence` | +0.5 |
| 她沉默时追问「你怎么了」 | 崩坏/低落期要求回应 | -3 |
| 同一句赞美第 3 回合再说 | 冷却内 | ×0.5 |
| 她哭时安静陪着 | 三轴全满 | +3 |
