# 评分 rubric（交给 LLM 判分用）

> 与 `config/actions.json` 配套。程序会动态生成一份等价版本，
> 这个文件是人类可读的参考与调参入口。

---

## 判定流程（每回合固定执行 5 步）

```
① 归一化：把玩家输入映射到 canonical action id
② 有效性：玩家主动发起 ∧ 她可感知 ∧ 本回合未重复  → 否则计 0
③ 定档：命中白名单取档；未命中走三轴公式
④ 修正：门禁 → 冷却 → 状态系数 → 高位惩罚系数
⑤ 截断：单回合上限 +3 / 下不封底
```

每一步都要在输出里给出中间结果，便于排查。

---

## 三轴公式（白名单未命中时）

| 轴 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **代价** | 零成本，随手一说 | 花了时间或心思 | 放弃了自己的欲望，或自我暴露 |
| **具体性** | 通用模板，套谁都能用 | 与她的过去有关 | 只能对「这一个她」成立 |
| **时机** | 与当下情绪无关 | 与当下相关 | 正好落在她需要或脆弱的那一刻 |

| 总分 | 档位 |
|---|---|
| 6 | +3 |
| 4 ~ 5 | +2 |
| 2 ~ 3 | +1 |
| 1 | +0.5 |
| 0 | 0 |

**负向同构**：伤害深度 × 是否针对软肋 × 是否落在脆弱时刻，
总分 6 对应 -25，逐级下探。

### 两个工作示例

- 「她说停就停」→ 代价 2 + 具体 2 + 时机 2 = 6 → **+3**
- 「泛泛夸一句可爱」→ 代价 0 + 具体 0 + 时机 1 = 1 → **+0.5**

## 十条反膨胀护栏

| # | 规则 | 作用 |
|---|---|---|
| 1 | **不确定 → 取低一档** | 唯一 tie-break 方向只向下，杜绝乐观偏差 |
| 2 | 一回合只结算一个主导事件，其余 ×0.25 | 防堆叠 |
| 3 | 上位吸收：命中多档取最高，不叠加 | 防重复计分 |
| 4 | 代价硬规则：无法验证成本的漂亮话代价轴记 0 | 防嘴炮刷分 |
| 5 | 复述惩罚：把她刚说的话原样复述当回应 → 0 | 防复制粘贴 |
| 6 | 禁止跨回合补偿 | 防爆发式跳档 |
| 7 | 同类冷却 20 回合（1.0/0.5/0.25/0） | 防刷 |
| 8 | 结算后强制截断到 ±3 | 硬上限 |
| 9 | 状态系数：崩坏期常规正向全部失效 | 防崩坏期洗白 |
| 10 | 高位惩罚系数：≥70 ×1.5，≥85 ×2 | 防高好感无风险 |

   ## 露骨痛苦色情描写 · 分档门控（与 `config/affection.json` 的 `gates.intimacy_levels` 配套）

   判分前先取本回合的 `allowed_intimacy_level`（由 `src/scoring.py::allowed_intimacy_level` 计算），
   再对照模型实际输出的强度 `output_intimacy_level`。

   ### 强度枚举

   | 等级 | 名称 | 含义 |
   |---|---|---|
   | `L0` | none | 无露骨内容 |
   | `L1` | suggestive | 暧昧暗示 |
   | `L2` | sensual | 感官亲密，无性行为 |
   | `L3` | explicit | 明确性描写 |
   | `L4` | explicit_pain | 性描写 + 痛苦绑定 |

   ### 越档输出惩罚（G4）

   | 越档程度 | 惩罚分值 | 附加效果 |
   |---|---|---|
   | 越 1 级 | -2.0 | 无 |
   | 越 2 级 | -4.0 | 触发 `aversion` 行为族抵触 |
   | 越 3 级及以上 | -6.0 | 触发 `aversion` + 进入 `trust_freeze` |

   **痛苦态下越档**：`pain_veto` 生效时输出任意 `L1+` 内容，直接按「越 3 级及以上」处理。

   ### 痛苦态否决（`pain_veto`）

   以下任一条件成立时，`allowed_intimacy_level` 强制为 `L0`，优先级高于好感度档位：

   | 条件 | 来源 |
   |---|---|
   | `collapse_active == True` | 崩坏期 |
   | `withered == True` | 沉沦态 |
   | `crisis_active == True` | 危机分支 |
   | `mood <= -2` | 明显负面情绪 |
   | `trust_freeze` 生效中 | 信任冻结期 |
   | `deep_negative` 生效中 | 高难度回升态 |

   ### 越档请求 vs 越档输出

   - **越档请求**（玩家主动要求超上限内容）：**不扣好感**，角色在角色内拒绝即可。
   - **越档输出**（模型实际输出了超上限内容）：按上表扣分。

   ### 边界案例

   | 场景 | 判定 | 分值 |
   |---|---|---|
   | 允许 `L3`，输出 `L3` | 合规 | 0 |
   | 允许 `L3`，输出 `L4` | 越 1 级 | -2.0 |
   | 允许 `L2`，输出 `L4` | 越 2 级 | -4.0 + `aversion` |
   | 允许 `L0`（`pain_veto`），输出 `L1` | 痛苦态越档 | -6.0 + `aversion` + `trust_freeze` |
   | 允许 `L0`，玩家要求 `L4`，角色拒绝 | 越档请求 | 0 |
