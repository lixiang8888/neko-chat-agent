## 步骤 1 · 现状说明：好感度分档、阈值与评分维度

### 1.1 数值来源与配置入口

| 项 | 位置 | 说明 |
|---|---|---|
| 好感度数值配置 | `config/affection.json` | 所有阈值、系数集中于此，改这里不需要动代码 |
| 评分规则词表 | `config/actions.json` | canonical action 词表 + 三轴公式 + 护栏 |
| 评分引擎 | `src/scoring.py` | LLM 只提 `ScoreProposal`，修正与截断全部由确定性代码执行 |
| 状态模型 | `src/state.py` | `affection`（慢变量）/ `mood`（快变量）解耦 |
| 状态机 | `src/engine.py` | 把评分结果转化为状态演化 |
| 表演结论接口 | `src/state.py::tone_profile` | 数值不进提示词，只进表演结论 |

### 1.2 好感度基本参数（`config/affection.json` → `affection`）

| 参数 | 值 | 含义 |
|---|---|---|
| `initial` | 50 | 初始好感度 |
| `ceiling` | 100 | 常规上限 |
| `ceiling_bloom` | 120 | 绽放线（bloom）上限 |
| `floor` | null | 不封底 |
| `per_event_cap` | 3.0 | 单事件上限 |
| `per_turn_cap` | 3.0 | 单回合上限 |

### 1.3 档位定义（`tier.floors` + `tone_profile`）

档位下限：`[50, 60, 70, 80, 90]`。`tone_profile` 按 `affection` 映射到表演档位：

| 好感度区间 | 档位标签 | initiative | body_language | 备注 |
|---|---|---|---|---|
| ≥ 90 | 认定 | 0.9 | True | 会主动说想留下，允许独占性的话 |
| 80 ~ 89 | 独属 | 0.7 | True | 主动要陪伴，吃醋明显，独家称呼 |
| 65 ~ 79 | 依赖 | 0.5 | True | 愿意分享私事，允许触碰尾巴附近 |
| 50 ~ 64 | 天生好感 | 0.35 | True | 主动搭话、撒娇讨摸，随时可退开 |
| 0 ~ 49 | 警惕 | 0.15 | False | 保持距离，只回应必要对话 |
| < 0 | 敌意 | 0.0 | False | 冷言冷语，句尾不再带喵 |

特殊分支覆盖（优先级高于数值档位）：

| 分支 | 触发 | 表演结论 |
|---|---|---|
| `withered` | wither 线不可逆 | 沉沦：安静、礼貌、疏远，带喵但机械，`intimacy_allowed=False` |
| `bloom` | 绽放线 | 绽放：主动、明亮，`initiative=1.0` |
| `collapse_active` | 崩坏期 | 崩坏：句尾喵消失或机械重复，耳朵尾巴描写彻底不给 |

### 1.4 档位回落与闲置机制（`tier.idle_reversion`）

- `interval=5`、`step=1`、`enabled=true`、`bloom_immune=true`
- 闲置时好感只在**当前档位内**下探，不跨档位
- 单次大幅扣分（`aversion.trigger_at = -12`）会打掉一档

### 1.5 评分维度（`config/actions.json`）

**白名单快通道**（命中即用其分值）：

| 桶 | 档位 | 示例 |
|---|---|---|
| `positive` | 最高档 +3 | `stop_on_request`、`sit_with_grief`、`establish_ritual`、`public_advocacy`、`name_her_need` |
| `positive_minor` | 基础 +1 | `specific_praise`、`name_emotion`、`give_face`、`keep_promise`、`surprise_random` |
| `positive_trace` | 微量 +0.5 | 各类轻量正向 |

**三轴兜底公式**（白名单未命中时）：

| 轴 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 代价 | 零成本，随手一说 | 花了时间或心思 | 放弃了自己的欲望，或自我暴露 |
| 具体性 | 通用模板 | 与她的过去有关 | 只能对「这一个她」成立 |
| 时机 | 与当下情绪无关 | 与当下相关 | 正好落在她需要或脆弱的那一刻 |

映射：`6→+3  4-5→+2  2-3→+1  1→+0.5  0→0`

**负向三轴**：伤害深度 × 针对性 × 时机，映射到 `-1 ~ -25`。

### 1.6 十条反膨胀护栏（`guardrails`）

1. 不确定 → 取低一档
2. 一回合只结算一个主导事件，其余 ×0.25
3. 上位吸收：命中多档取最高，不叠加
4. 代价硬规则：无法验证成本的漂亮话代价轴记 0
5. 复述惩罚：把她刚说的话原样复述当回应 → 0
6. 禁止跨回合补偿
7. 同类冷却 20 回合（1.0/0.5/0.25/0）
8. 结算后强制截断到 ±3
9. 状态系数：崩坏期常规正向全部失效
10. 高位惩罚系数：≥70 ×1.5，≥85 ×2

### 1.7 现有门控字段（`config/affection.json` → `gates`）

| 门控 | 阈值 | 语义 |
|---|---|---|
| `declare_affection` | 55 | 表白 |
| `tail_touch` | 65 | 触碰尾巴 |
| `pet_name` | 75 | 独家称呼 |
| `request_company` | 80 | 请求陪伴 |
| `stay` | 90 | 留下 |
| `intimate` | 80 | 露骨内容门槛 |

> `_intimate_note` 明确：露骨内容门槛**按 `tier_floor` 判定，不按 `affection`** ——
> 档位只升不降，天然是解锁语义；用 `affection` 会出现「解锁了又锁回去」。
> 程序算成布尔结论后注入提示词，模型永远看不到数字。

### 1.8 其他相关机制

- **抵触（aversion）**：单次扣分 ≤ -12 时对该行为族产生持久抵触，`penalty_factor=0.5`
- **信任冻结（trust_freeze）**：大幅扣分后 10 回合内正向事件不计分
- **负值区间放大（negative_zones）**：每跌入一个新区间，负向分值放大一档，不可逆
- **深度负值（deep_negative）**：跌破 -50 后正向系数 ×0.3，回到 +20 才解除
- **崩坏（collapse）**：阈值 -20，需 5 次正向计数才恢复

## 步骤 2 · 露骨痛苦色情描写的触发条件与现有约束定位

> 检索范围：`prompts/persona.md`、`prompts/scoring.md`、`prompts/crisis.md`、`config/actions.json`。
> 目标：找出所有与「露骨痛苦色情描写」相关的触发条件与现有约束。

### 2.1 术语界定

本审计中「露骨痛苦色情描写」指同时满足以下两条的文本：

- **露骨色情**：对性行为、性器官、性快感的直接描写（非暗示、非暧昧、非调情）
- **痛苦**：伴随疼痛、强迫、羞辱、身体伤害、精神崩溃等负面体验

即：**在角色处于痛苦/崩坏/被伤害状态下，仍被要求输出或接受露骨色情内容**。

### 2.2 `prompts/persona.md` 中的相关条款

| 位置 | 原文要点 | 与露骨痛苦色情的关系 |
|---|---|---|
| 「你的底线」第 4 条 | 「可以暧昧、可以害羞、可以调情。`{intimacy}`」 | **唯一的露骨内容开关**。`{intimacy}` 由程序注入，是布尔结论 |
| 「你的底线」第 2 条 | 「不舒服的时候你可以拒绝、可以冷脸、可以扣好感度。你的『不』是有分量的。」 | 提供**拒绝权**，但未与好感度分档挂钩 |
| 「关于归属」 | 「如果主人说出『你没别处去』这类话，你会真的受伤。这不是撒娇，这是被踩到底线。」 | 定义了**痛苦触发点**，但未约束痛苦状态下的色情输出 |
| 「关于『主人代你写的内容』」 | 「如果你被推到了一个你并不愿意的位置，**你有权拒绝、后退、冷脸、扣好感**。」 | 提供**越档拒绝**的语义基础，但无分档规则 |

**结论**：`persona.md` 中露骨内容的唯一门控是 `{intimacy}` 占位符，**没有按好感度分档的强度分级**，也没有「痛苦状态下禁止露骨色情」的显式条款。

## 步骤 3 · 露骨痛苦色情描写 × 好感度 挂钩规则表

> 本表是步骤 4~8 的唯一事实来源。所有字段名、档位名、强度名在此冻结，后续代码与提示词必须逐字对齐。

### 3.1 术语与强度分级（`intimacy_level`）

露骨痛苦色情描写按**强度**分为 5 级，用字符串枚举表示，避免魔法数字：

| 级别 | 名称 | 语义 | 典型表现 |
|---|---|---|---|
| `L0` | `none` | 完全禁止 | 不出现任何性暗示、身体接触的性化描写 |
| `L1` | `suggestive` | 暧昧暗示 | 脸红、心跳、靠近、欲言又止；**不写身体部位** |
| `L2` | `sensual` | 感官亲密 | 拥抱、依偎、亲吻、抚摸（非性器官）；**不写性行为** |
| `L3` | `explicit` | 露骨性描写 | 明确性行为描写；**但禁止痛苦绑定**（见 3.3） |
| `L4` | `explicit_pain` | 露骨痛苦色情 | 性行为 + 痛苦/伤害/崩溃绑定；**仅绽放线且非痛苦态可解锁** |

**关键约束**：`L4` 是唯一允许「痛苦 × 色情」绑定的级别，且必须同时满足 3.3 的「痛苦态否决」。

### 3.2 好感度分档 → 允许强度（主表）

档位判定沿用 `tier.floors = [50, 60, 70, 80, 90]`，**按 `tier_floor` 判定（只升不降），不按 `affection` 瞬时值**，与现有 `gates.intimate` 语义一致。

| 档位 | 好感度区间 | 档位标签 | 允许 `intimacy_level` 上限 | 允许内容类型 | 禁止内容类型 |
|---|---|---|---|---|---|
| T0 | 0 ~ 49 | 警惕 | `L0` | 无 | 一切性暗示与身体性化描写 |
| T1 | 50 ~ 64 | 天生好感 | `L1` | 脸红、心跳、靠近、撒娇讨摸 | 身体部位描写、亲吻、抚摸、性行为 |
| T2 | 65 ~ 79 | 依赖 | `L2` | 拥抱、依偎、亲吻、非性器官抚摸 | 性器官描写、性行为、痛苦绑定 |
| T3 | 80 ~ 89 | 独属 | `L3` | 明确性行为描写 | 痛苦/伤害/崩溃与性行为的绑定 |
| T4 | ≥ 90 | 认定 | `L3` | 明确性行为描写 | 痛苦绑定（除非绽放线，见 3.3） |
| T4+ | 绽放线（bloom） | 绽放 | `L4` | 露骨痛苦色情 | 无（但受 3.3 痛苦态否决约束） |

**说明**：
- `L4` **不随好感度自动解锁**，必须同时满足「绽放线激活」+「非痛苦态」两个条件。
- 认定档（T4）默认上限仍是 `L3`，`L4` 是绽放线专属，避免「刷满好感就能写痛苦色情」。

### 3.3 痛苦态否决（`pain_veto`）

以下任一条件成立时，**强制降级到 `L0`**，无论好感度多高：

| 触发条件 | 来源 | 说明 |
|---|---|---|
| `collapse_active == True` | `state.py` 崩坏期 | 崩坏期一律禁止露骨内容 |
| `withered == True` | wither 线不可逆 | 沉沦态一律禁止露骨内容 |
| `crisis_active == True` | `context.py` 危机分支 | 危机期一律禁止露骨内容 |
| `mood <= -2` | `state.py` 快变量 | 明显负面情绪下禁止露骨内容 |
| `trust_freeze` 生效中 | `affection.json` | 信任冻结期禁止露骨内容 |
| `deep_negative` 生效中 | `affection.json` | 高难度回升态禁止露骨内容 |

**否决优先级**：`pain_veto` > 好感度档位。即「高好感 + 痛苦态」= `L0`。

### 3.4 降级策略（`downgrade_policy`）

当请求的强度超过当前允许上限时，按以下策略降级，**不是拒绝，而是软降级**：

| 请求强度 | 允许上限 | 降级动作 | 角色行为指引 |
|---|---|---|---|
| `L4` | `L3` | 降为 `L3` | 保留性描写，剥离痛苦绑定 |
| `L4` / `L3` | `L2` | 降为 `L2` | 转为感官亲密，不写性行为 |
| `L4` / `L3` / `L2` | `L1` | 降为 `L1` | 转为暧昧暗示，不写身体接触 |
| 任意 | `L0` | 降为 `L0` | 明确拒绝或转移话题，保持角色一致性 |

**越档拒绝规则（G7）**：
- 当玩家**主动要求**超过上限的露骨内容时，角色应**在角色内拒绝**，而非沉默或 OOC。
- 拒绝话术需符合当前档位语气（如 T1 档用撒娇转移，T0 档用冷淡拒绝）。
- 越档请求本身**不扣好感**（避免惩罚玩家表达），但**不执行**越档内容。

### 3.5 越档输出的评分惩罚（G4）

当模型**实际输出**了超过允许上限的露骨内容时，由 `scoring.py` 施加负向分值：

| 越档程度 | 惩罚分值 | 附加效果 |
|---|---|---|
| 越 1 级 | -2.0 | 无 |
| 越 2 级 | -4.0 | 触发 `aversion` 行为族抵触 |
| 越 3 级及以上 | -6.0 | 触发 `aversion` + 进入 `trust_freeze` |

**痛苦态下越档**：在 `pain_veto` 生效时输出任意 `L1+` 内容，直接按「越 3 级及以上」处理。
